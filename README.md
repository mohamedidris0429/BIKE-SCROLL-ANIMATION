# 🏍️ Scroll Animation Bike Website

My first website project — a modern scroll-based bike animation website created to explore web development, animations, and creative UI design.

## 🚀 About the Project

This project is a scroll animation website where the bike and other visual elements interact with the user's scrolling.

I created this project as my first step into web development and to experiment with modern website animations and interactive experiences.

- ⚡ Interactive scrolling experience
- 💻 Clean and creative web design
